# שלט USB ל-Call of Duty Mobile

אפליקציית אנדרואיד שמאפשרת לשחק COD Mobile עם כל שלט בחיבור USB-C, בלי Shizuku ובלי Termux.

## הורדה
[CodUsbController.apk](https://github.com/gadits/cod-usb-controller-/releases/download/latest/CodUsbController.apk) (הגרסה האחרונה תמיד בקישור הזה)

## איך זה עובד
האפליקציה מתחברת ל"ניפוי באגים אלחוטי" של המכשיר עצמו, ודרכו יוצרת שלט וירטואלי בשם
"Xbox Wireless Controller". המשחק מזהה אותו, מפעיל מצב שלט, ומקבל גם את הלחיצות מהשלט שמחובר ב-USB.

## הגדרה חד-פעמית
1. אפשרויות מפתח: הגדרות ← מידע על הטלפון ← 7 לחיצות על "מספר Build" / "גרסת MIUI".
2. באפליקציה: "התחל צימוד" ← להדליק "ניפוי באגים אלחוטי" ← "צימוד מכשיר באמצעות קוד צימוד" ← להקליד את הקוד בהתראה.
3. בשיאומי: לאשר "הפעלה אוטומטית", ולהדליק "ניפוי באגים USB (הגדרות אבטחה)" כדי שההפעלה אחרי הדלקה תעבוד.

מאותו רגע השלט הווירטואלי עולה לבד בכל הדלקה של המכשיר (בזמן חיבור ל-WiFi).

## דרישות
- אנדרואיד 11 ומעלה
- חיבור WiFi בזמן ההפעלה
